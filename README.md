# ТЬМА ЗА СПИНОЙ

### ▶ [Играть](https://ykrivochurov.github.io/tma-za-spinoy/)

Precision-платформер про перегоны заброшенного метро. Силуэтная графика
в духе Limbo, физика в духе Celeste, **ноль файлов-ассетов**: картинка,
анимация и звук синтезируются кодом.

Герой и твари не имеют ни одного кадра анимации — позы считаются каждый кадр
из состояния физики через скелет и обратную кинематику. Архитектура метро
строится параметрически от одной точки схода. Звук — Web Audio из двух
примитивов: осциллятор со свипом и отфильтрованный шум.

Свет — не декорация: конус фонаря показывает детали и отгоняет тварей,
но геометрию видно всегда, поэтому ни одна смерть не бывает вслепую.

```bash
npm install
npm run dev
```

## Управление

| Клавиши | Действие |
|---|---|
| `←` `→` / `A` `D` | Бежать |
| `Z` / `Space` / `J` | Прыжок (держать дольше — выше) |
| `X` / `Shift` / `K` | Рывок в любую из 8 сторон |
| `↑` `↓` | Светить выше / ниже, `↓` — ещё и быстрое падение |
| `R` | Рестарт перегона |
| `1`–`8` | Прыжок в перегон |
| `M` | Звук вкл / выкл |
| `F1` | Debug-оверлей |

Прижмись к стене в воздухе и прыгай — отскок несёт вверх и в сторону.
Рывок восполняется при касании земли и от батареи.
